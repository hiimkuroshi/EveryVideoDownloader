# UI concept prompts

Generated with the built-in ImageGen tool as high-fidelity `ui-mockup` previews.

All three concepts use the same functional structure: compact brand/header, URL analysis bar, four primary tabs, left video inspector, right format explorer and sticky download action. Required visible labels include “Phân tích”, “Studio”, “Hàng chờ”, “Nâng cao”, “Cài đặt” and “Tải xuống”. All concepts exclude “yt-dlp”, “Powered by”, device frames and watermarks.

## A — Graphite Signal

Production-grade dark media workstation using cool graphite and charcoal surfaces, off-white typography and one signal-coral accent. Status colors are semantic only. Geometric sans-serif UI with monospaced technical data; restrained motion and effects; no purple gradient, glow-heavy styling or glassmorphism.

## B — Arctic Cobalt

Production-grade bright utility interface using arctic white, pale cool gray, ice-blue surfaces, dark navy text and one cobalt accent. Airy but not sparse, highly legible and calm; no excessive rounded cards, glassmorphism or generic SaaS-dashboard styling.

## C — Studio Noir

Production-grade cinematic workstation using near-black, carbon and smoked-metal surfaces, warm-gray typography and one amber-orange accent. Compact dense grid with thin technical dividers; inspired by professional editing/audio suites without copying an existing product; no neon cyberpunk palette, strong glow or glassmorphism.

## D — Carbon Mint

Ultra-modern neo-minimal productivity interface using carbon black, ink-gray, soft-white text and one fresh mint accent. Typography-led, almost borderless, with matte surfaces, subtle grain, compact technical density and a numbered workflow. No card soup, glassmorphism or neon glow.

## E — Spatial Glass

Modern spatial desktop interface using smoky blue-black, titanium-gray translucent panels and one cyan/aqua accent. Restrained frosted depth, readable transparency, satin dividers and a compact navigation rail. No purple AI gradient, decorative blobs or excessive glow.

## F — Neo Editorial

Premium neo-editorial creative tool using mineral off-white, deep ink, black structural lines and one vermilion-red accent. Swiss-grid discipline, asymmetric whitespace, expressive typography, minimal containers and a bold download strip. No rounded-card dashboard cliché or generic SaaS styling.
