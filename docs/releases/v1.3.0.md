# EveryVideo v1.3.0 — Windows x64

Bản mới bổ sung giao diện Velvet Silk, tự ghép audio khi chọn video-only và kiểm tra cập nhật từ GitHub. Kèm sẵn Node.js, Python/core, FFmpeg/FFprobe, aria2 và Chromium headless.

## Chọn bản tải

| File | Cách dùng |
| --- | --- |
| **EveryVideo-1.3.0-Portable-Folder-x64.zip** | **Khuyến nghị portable:** giải nén toàn bộ một lần rồi mở `EveryVideo.exe`; giữ nguyên các tài nguyên đi kèm. |
| EveryVideo-1.3.0-Setup-x64.exe | Bộ cài Windows x64 cho tài khoản hiện tại, có shortcut và gỡ cài đặt. |
| EveryVideo-1.3.0-Portable-x64.exe | Một file mở trực tiếp; giải nén lại runtime vào thư mục tạm mỗi lần mở nên khởi động chậm hơn ZIP đã giải nén. |
| SHA256SUMS.txt | Mã SHA-256 để kiểm tra các file tải. |

## Thay đổi chính

- Giao diện Velvet Silk với bốn bảng màu và bốn bộ font trong Cài Đặt, lưu lựa chọn trên máy.
- Ưu tiên bảng định dạng trong Studio; nguồn media chuyển sang tab phụ, hỗ trợ bàn phím và giữ bộ lọc/lựa chọn.
- Chọn video-only mặc định ghép thêm audio, kể cả trong hàng chờ; có thể chọn audio thủ công hoặc tải riêng luồng gốc.
- Nguồn media đề xuất audio cùng nội dung, ghép bằng FFmpeg và báo lỗi rõ nếu audio không tải được.
- Kiểm tra bản EveryVideo mới trong Cài Đặt, so phiên bản và mở trang tải trên GitHub; tải/cài thủ công.
- Giữ hỗ trợ bốn ngôn ngữ, tải/hủy và runtime tích hợp. Gói không kèm cấu hình, cookie hay media cá nhân từ máy build.

## Kiểm chứng và giới hạn

Kiểm tra trên Windows bằng dữ liệu thử riêng: giao diện, API, runtime tích hợp, phân tích fixture, ghép video/audio với FFprobe, hủy, lưu cấu hình và dừng tiến trình khi thoát. Portable EXE được kiểm tra từ wrapper thực tế; source và checksum được đối chiếu với gói phát hành.

Các gói **chưa ký số nhà phát hành**; chưa kiểm thử cài/gỡ trên VM Windows sạch. Khả năng tải phụ thuộc website và quyền truy cập nội dung. Cấu hình lưu trong app-data EveryVideo và được giữ khi nâng cấp; thư mục tải có thể đổi trong ứng dụng.
