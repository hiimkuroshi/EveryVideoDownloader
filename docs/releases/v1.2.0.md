# EveryVideo v1.2.0 — Windows x64

EveryVideo có cửa sổ ứng dụng riêng và kèm Node.js, Python, FFmpeg/FFprobe, aria2 cùng Chromium headless. Không cần cài các runtime này riêng.

## Chọn bản tải

| File | Cách dùng |
| --- | --- |
| **EveryVideo-1.2.0-Portable-Folder-x64.zip** | **Khuyến nghị dùng portable:** giải nén toàn bộ một lần vào thư mục riêng, sau đó mở `EveryVideo.exe`. Giữ nguyên các file/thư mục đi kèm. |
| EveryVideo-1.2.0-Setup-x64.exe | Bộ cài cho tài khoản Windows hiện tại, có shortcut và gỡ cài đặt. |
| EveryVideo-1.2.0-Portable-x64.exe | Một file mở trực tiếp; giải nén lại ứng dụng vào thư mục tạm mỗi lần chạy nên mở chậm hơn bản ZIP đã giải nén hoặc bản đã cài. |
| SHA256SUMS.txt | Mã SHA-256 để kiểm tra các gói tải. |

## Thay đổi chính

- Thêm desktop shell với backend loopback, cấu hình riêng và dừng các tiến trình tải khi thoát.
- Khám phá nhiều video/audio/ảnh/phụ đề từ HTTP, HTML, JSON, iframe và trang tương tác; hỗ trợ xem trước, sao chép URL, tải và hủy.
- Cải thiện Studio, preset chất lượng, hàng chờ, giao diện đa ngôn ngữ và tiến độ tải.
- Giữ core yt-dlp tùy biến và khả năng tăng tốc Bilibili bằng aria2.
- Sắp xếp tài liệu và kế hoạch; các gói không mang config, cookie, profile hay media cá nhân từ máy build.

Cấu hình được lưu trong thư mục app-data của EveryVideo, kể cả khi dùng portable. Thư mục tải mặc định là Downloads/EveryVideo và có thể thay đổi trong ứng dụng. Đóng ứng dụng sẽ dừng tác vụ đang tải.

## Kiểm chứng và giới hạn

Đã kiểm tra trên host Windows bằng dữ liệu riêng và PATH chỉ chứa thư mục hệ thống: giao diện, runtime đi kèm, phân tích metadata, tải DASH/ghép audio-video bằng FFmpeg, hủy, lưu cấu hình và dọn tiến trình khi thoát. Bản portable EXE cũng được kiểm tra từ wrapper thực tế.

Các gói Windows **chưa ký số nhà phát hành**. Chưa kiểm thử cài/gỡ trên VM Windows sạch. Khả năng trích xuất nội dung còn phụ thuộc website, đăng nhập và các hạn chế truy cập của nguồn.

Giấy phép và thông báo cho các thành phần đi kèm nằm trong gói, gồm `THIRD-PARTY-NOTICES.txt`, license runtime và source core yt-dlp.
